# OSINT Telegram Bot — Maigret + SpiderFoot

Telegram-бот для работы с открытыми источниками:

- **Maigret 0.6.5** — поиск публичных профилей по username.
- **SpiderFoot 4.0** — сбор открытой информации по доменам и публичным IP.
- **Telegram Stars** — платные запросы для обычных пользователей.
- **Админ-режим** — бесплатные запросы и выдача бесплатных запросов пользователям.

## Оплата и бесплатные запросы

По умолчанию один `/username` или `/scan` стоит **50 Telegram Stars**.

Логика:

1. Администратор выполняет запросы бесплатно.
2. Если у пользователя есть бесплатные запросы, сначала расходуется один из них.
3. Если бесплатных запросов нет, бот выставляет счёт на 50 ⭐ в валюте `XTR`.
4. До `successful_payment` OSINT-запрос не запускается.
5. После подтверждённой оплаты бот запускает запрос автоматически.
6. Платёж сохраняется в SQLite вместе с `telegram_payment_charge_id`.
7. Если оплаченный запрос не завершился, `/retry` запускает его снова без повторной оплаты.
8. Если бесплатный запрос не удалось выполнить, он возвращается пользователю на баланс.

## Команды

- `/start` — справка и статус
- `/username` — бот попросит username следующим сообщением
- `/username example` — сразу запустить поиск по username
- `/scan` — бот попросит домен/IP следующим сообщением
- `/scan example.com` — сразу запустить SpiderFoot
- `/balance` — показать бесплатные запросы
- `/retry` — повторить оплаченный незавершённый запрос
- `/cancel` — остановить текущий процесс
- `/terms` — условия оплаты
- `/support` — поддержка

Команды администратора:

- `/admin` — статистика и админ-команды
- `/give @username 5` — выдать пользователю 5 бесплатных запросов

Чтобы `/give` работал по username, пользователь должен хотя бы один раз открыть бота и отправить `/start`. Бот сохраняет соответствие Telegram user ID и текущего username в SQLite.

## Переменные окружения

Обязательно:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

Настройки:

```env
ADMIN_IDS=8196658213
ALLOWED_USER_IDS=
MAX_CONCURRENT_SCANS=1
SCAN_TIMEOUT_SECONDS=300
RATE_LIMIT_SECONDS=30
REPORT_TTL_HOURS=24
PRICE_STARS=50
MAX_GIFT_CREDITS=1000
LOG_LEVEL=INFO
SUPPORT_TEXT=По вопросам оплаты и работы бота обратитесь к владельцу бота.
```

Для публичного платного бота `ALLOWED_USER_IDS` оставляют пустым. `ADMIN_IDS` может содержать несколько ID через запятую.

## Docker

```bash
docker build -t osint-telegram-bot .
docker run --rm \
  -e BOT_TOKEN="YOUR_TOKEN" \
  -e ADMIN_IDS="8196658213" \
  -e PRICE_STARS="50" \
  osint-telegram-bot
```

Docker устанавливает Maigret 0.6.5 и SpiderFoot 4.0 в отдельные virtualenv. Для SpiderFoot в Dockerfile заменяется устаревшее ограничение PyYAML на совместимую с Python 3.11 ветку 6.x.

## Amvera

Проект запускается через `Dockerfile` и Telegram long polling, веб-порт ему не нужен.

В Amvera добавьте как минимум:

```env
BOT_TOKEN=...
ADMIN_IDS=8196658213
PRICE_STARS=50
```

**Важно:** `data/payments.sqlite3` хранит пользователей, бесплатные запросы и платежи. Для продакшена каталог `data` желательно подключить к постоянному хранилищу Amvera. Иначе при полном пересоздании контейнера локальная база может быть потеряна.

## Надёжность и безопасность

- subprocess запускается без shell-интерпретации;
- один пользователь не может одновременно поставить несколько OSINT-задач;
- есть глобальный лимит параллельных сканирований;
- есть timeout и `/cancel`;
- отчёты автоматически чистятся каждый час по TTL;
- username и цели валидируются;
- локальные, private, loopback, link-local и reserved IP блокируются;
- домены дополнительно резолвятся перед SpiderFoot и отклоняются, если ведут во внутреннюю сеть;
- SpiderFoot JSON проверяется перед отправкой;
- платежи проверяются по пользователю, валюте `XTR`, сумме и payload;
- оплаченный незавершённый запрос не требует второй оплаты;
- SQLite работает в WAL-режиме с busy timeout;
- токен бота не хранится в репозитории.

Используйте бот только для открытых данных и целей, которые вам разрешено проверять.
